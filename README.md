
# Wine Quality Assistant

Демо-приложение на Streamlit для оценки вероятности того, что вино относится к хорошим.

## Содержимое проекта

- `app.py` — веб-приложение.
- `model.joblib` — обученный пайплайн масштабирования и логистической регрессии.
- `config.json` — порог классификации по умолчанию.
- `test.csv` — тестовая выборка для визуализации метрик.
- `requirements.txt` — зависимости проекта.

## Требования

Python 3.11.

## Установка

Создайте виртуальное окружение и установите зависимости.

Windows:

```bash
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

macOS / Linux:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Запуск

```bash
streamlit run app.py
```

Streamlit откроет локальную веб-страницу в браузере.

## Кэширование

`st.cache_resource` используется для загрузки модели, поскольку модель — общий ресурсоёмкий объект, который можно повторно использовать между перезапусками приложения.

`st.cache_data` используется для таблиц и рассчитанных вероятностей. Такие результаты можно кэшировать и повторно использовать без повторного чтения CSV и повторного вызова `predict_proba` при каждом изменении порога.

Без кэширования `joblib.load` выполнялся бы при каждом перезапуске скрипта, а вероятности на тестовой выборке пересчитывались бы при каждом изменении порога, замедляя работу приложения.
